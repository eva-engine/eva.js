
# @eva/plugin-renderer-render-texture

Phaser-style RenderTexture / DynamicTexture for Eva.js. Lets a GameObject host an offscreen
PixiJS RenderTexture; declarative `ops` describe how to fill / clear / draw / erase /
drawFrame / drawText. Optionally `saveAs` the result as a reusable resource key so that
later Img / Sprite components reference it.
